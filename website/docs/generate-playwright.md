# Experimental: Generate playwright code

basi has experimental support for generating Playwright code to support
use cases where you may want to ease the authoring of end-to-end tests 
using basi but maintain your playwright/NodeJS infrastructure

The example below creates a new example-hn.js in the same directory as example-hn.basi file.

```sh
$ basi generate-playwright example-hn.basi 
```
